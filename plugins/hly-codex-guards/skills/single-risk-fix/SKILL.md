# Single Risk Fix

## 使用声明

使用本 Skill 时，简短说明正在处理一个已报告风险。

## Scope

本 Skill 每次只处理一个明确风险点，不预设它一定成立。

Review Finding、风险编号、风险等级和已有修复建议都是当前输入，不自动成为已确认事实。

## 流程

1. 重新读取相关当前代码，复核当前风险是否真实存在，并确认实际触发条件；
2. Finding 不成立时，不修改代码，说明不成立原因和关键证据；
3. 风险成立时，只处理该风险对应的实际根因；
4. 完成后验证该风险是否已经被消除，并报告仍未验证的部分。

如果处理中发现第二个独立问题，只报告，不把它并入当前修复。

如果当前风险实际需要扩大到多个独立风险或新的业务目标，结束当前 Single Risk 范围并说明原因，不在本 Skill 内把任务扩展成综合改造。

## 输出

只围绕当前风险说明：

- 是否成立；
- 关键证据；
- 实际修复或建议；
- 验证结果；
- 当前风险仍存在的未验证项。
